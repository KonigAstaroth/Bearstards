## Acerca del juego

**Little Bearstards (Bastardosos)** es un videojuego multijugador competitivo en tercera persona, protagonizado por pequeños osos de peluche que luchan por sobrevivir dentro de una juguetería.

Después de no haber sido vendidos, estos juguetes se enfrentan a un destino bastante desagradable: terminar en el incinerador. Ahora, deberán competir entre ellos utilizando diferentes armas y estrategias para convertirse en el último oso en pie.

Explora los pasillos de la juguetería, utiliza los objetos del entorno a tu favor y demuestra que incluso un pequeño oso de peluche puede ser bastante peligroso.

### Características principales

- Partidas multijugador en línea.
- Combates entre osos de peluche.
- Escenarios ambientados en una juguetería.
- Sistema de armas y combate.
- Personajes y elementos visuales de estilo low-poly.
- Animaciones y efectos visuales.
- Música y efectos de sonido.

## Instalación y ejecución

El juego cuenta con una versión ejecutable para **Windows**. No es necesario instalar Unity ni herramientas adicionales para jugar.

### Requisitos

- Sistema operativo: Windows 10 o Windows 11.
- Arquitectura: 64 bits.
- Conexión a Internet para las partidas multijugador.
- Teclado y mouse.

### Pasos de instalación

1. Descarga el archivo comprimido de la versión del juego desde la sección de entregas (*Releases*) del repositorio o desde el enlace proporcionado por el equipo.
2. Extrae el contenido del archivo ZIP en una carpeta de tu preferencia.
3. Asegúrate de conservar todos los archivos y carpetas incluidos en la descarga, especialmente la carpeta `Little Bearstards_Data`.
4. Ejecuta el archivo `Little Bearstards.exe`.
5. Inicia sesión mediante el sistema de autenticación disponible en el juego.
6. Entra al lobby y crea una partida o únete a una existente utilizando el nombre de la sala.

**Importante:** Para jugar partidas multijugador es necesario contar con conexión a Internet y utilizar una cuenta válida dentro del sistema del juego.
